# 出口技术通知助手

Windows 本地工具，读取一批 Excel，按负责产品资料表筛选，生成可编辑 Word 和来源校验报告。

## 使用

1. 打开便携目录中的“出口技术通知助手.exe”。整个目录一起保留或移动，不能只复制 exe。
2. 把同一合同、同一车型的一批 .xlsx / .xls 文件放在一个文件夹中。
3. 选择批次文件夹、产品资料表、Word 模板和输出目录。
4. 填写通知编号和实施日期，点击“读取并预览”，查看负责产品、排除产品、要求和字段来源。
5. 点击“校验并生成通知”。输出在批次名称加时间的子目录中。
6. 打开 Word 和校验报告，人工审核后下发。程序不会读取邮箱或自动下发。

附带的“样例批次”使用用户提供的真实 Excel。产品资料表仅初始化两个已确认负责图号，其固定资料来自人工完成的技术通知样例。通知编号“样例-001”仅用于演示。

## 维护产品资料

打开 data/产品资料表.xlsx，在“产品资料”工作表每行增加一个标准图号；不要重复图号或把说明写成产品记录。是否负责、是否启用用“是/否”控制，非负责、未启用和未知图号进入排除清单。图号的 -ck、+ck 后缀只归一化，不用于判断归属。

英文名称、包装模数、单箱数量、纸箱尺寸、重量说明：本批 Excel 明确值优先，否则回退资料表。包装模数和单箱数量是不同字段，程序不会互相替代。工位号只使用 Excel 明确值，未说明固定写 /，不会回退资料表工位号。

国家和 LOGO：仅采用明确字段或禁止要求，禁止显示时用 /；缺失或矛盾时阻断。合同号、车型、英文名称、中文名称、重量说明及必要包装资料缺失时阻断。数量、模数、单箱数量必须是正整数，数量不能被单箱数量整除时阻断。完成日期来自 Excel 的计划时间，未说明用 /，不会取实施日期。

重复图号：数量、包装参数或要求不同即阻断；完全一致的记录不重复生成，所有来源仍记录在报告。不同合同或车型需要拆成不同批次。

## 列名和要求识别

支持中文与英文常见列名；data/字段别名.json 可增加 en、modulus、units、carton_size、station 等字段别名。列名匹配忽略空格和常见标点。备注中的“英文名称：”“每箱数量：”“纸箱尺寸：”“工位号：”等明确字段也可读取。未知自由文本不推断参数；它保存在校验报告中供复核。

标签网址为必填。供货通知正文保留技术要求，群通知开头和重复网址在正文中整理，完整原文及文件/工作表/行号保存在“要求来源”工作表。Excel 公式读取已有缓存值；没有缓存的必填值会校验失败。

## 模板

data/自动化模板.docx 已从旧 .doc 转换，保留首页表格、包装要求、签批和页眉水印，移除原来的空白页，明细改为动态双栏信息表。固定首页包装文字是模板规则；有批次例外时先修改模板，再人工复核，避免与批次正文冲突。

模板使用普通 {{通知编号}}、{{实施日期}}、{{合同号}}、{{车型}}、{{通用技术要求}}、{{标签网址}} 和动态明细 {{图号}} 等槽位，也兼容 {{row.code}} 等英文槽位。不要删除必要占位符。增加产品时复制动态模板行，生成时保留字体、边框和行样式。原始桌面 .doc 和 .xlsx 均未修改。

## 开发运行

Python 3.11 及以上：

    python -m pip install -r requirements.txt
    python app.py

命令行生成：

    python -m export_notice examples/样例批次 --master data/产品资料表.xlsx --template data/自动化模板.docx --output outputs --number 示例编号 --date 2026-10-12

运行测试（旧版 Excel 测试另需 xlwt）：

    python -m pip install xlwt
    python -m unittest discover -s tests -v

构建 Windows 便携程序需要 PyInstaller：

    python -m PyInstaller --noconfirm --clean --windowed --onedir --name 出口技术通知助手 app.py

构建后把 data、examples 和本说明复制到 exe 同级目录。日常运行不需要 Python、LibreOffice 或邮箱账号。

已使用 xlrd 读取 .xls，PyInstaller 打包，LibreOffice 26.2.6 转换旧 Word 并渲染验证；这些开发工具不参与日常生成流程。
